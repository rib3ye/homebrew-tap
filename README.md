# homebrew-tap

A [Homebrew](https://brew.sh) tap for rib3ye's command-line tools.

## Install

```sh
brew install rib3ye/tap/yt-audio
```

Or tap first, then install by name:

```sh
brew tap rib3ye/tap
brew install yt-audio
```

## Formulae

| Formula | Description |
| ------- | ----------- |
| [`yt-audio`](Formula/yt-audio.rb) | Download YouTube audio in the highest quality the macOS Music app plays. ([source](https://github.com/rib3ye/yt-audio)) |
